                <section>
                    <h3>📈 Что такое доходность?</h3>
                    <p><strong>Доходность</strong> — процентное изменение стоимости портфеля за период.</p>
                    <br>
                    <p><strong>Виды доходности:</strong></p>
                    <ul>
                        <li><strong>Абсолютная</strong> — в денежном выражении (например, +50 000 ₽)</li>
                        <li><strong>Относительная</strong> — в процентах (например, +25%)</li>
                        <li><strong>Реальная</strong> — с учётом инфляции</li>
                        <li><strong>Номинальная</strong> — без учёта инфляции</li>
                    </ul>
                </section>
                
                <section>
                    <h3>🧮 Формула доходности</h3>
                    <p><strong>Простая доходность:</strong></p>
                    <br>
                    <div style="background: #1e1e2e; padding: 20px; border-radius: 12px;">
                        <code style="font-size: 1.2em;">R = (P_кон - P_нач + D) / P_нач × 100%</code>
                    </div>
                    <br>
                    <ul>
                        <li><strong>P_нач</strong> — начальная стоимость портфеля</li>
                        <li><strong>P_кон</strong> — конечная стоимость портфеля</li>
                        <li><strong>D</strong> — полученные дивиденды/купоны</li>
                    </ul>
                </section>
                
                <section>
                    <h3>📅 Годовая доходность (CAGR)</h3>
                    <p><strong>CAGR</strong> (Compound Annual Growth Rate) — среднегодовой темп роста.</p>
                    <br>
                    <div style="background: #1e1e2e; padding: 20px; border-radius: 12px;">
                        <code style="font-size: 1.2em;">CAGR = (P_кон / P_нач)^(1/n) - 1</code>
                    </div>
                    <br>
                    <p>где <strong>n</strong> — количество лет</p>
                </section>
                
                <section>
                    <h3>📝 Пример расчёта доходности</h3>
                    <p><strong>Исходные данные:</strong></p>
                    <ul>
                        <li>Начальный капитал: <strong>100 000 ₽</strong></li>
                        <li>Конечный капитал: <strong>150 000 ₽</strong></li>
                        <li>Дивиденды: <strong>5 000 ₽</strong></li>
                        <li>Период: <strong>2 года</strong></li>
                    </ul>
                    <br>
                    <p><strong>Расчёт:</strong></p>
                    <p>Общая доходность = (150 000 - 100 000 + 5 000) / 100 000 = <strong style="color:#4ade80;">55%</strong></p>
                    <p>Годовая доходность (CAGR) = (1.55)^(1/2) - 1 = <strong style="color:#4ade80;">24.5%</strong></p>
                </section>
                
                <section>
                    <h3>💻 Программа для расчёта доходности</h3>
                    <pre><code style="font-size: 0.65em;">
def calculate_return(start, end, dividends=0, years=1):
    """Расчёт доходности портфеля"""
    total_return = (end - start + dividends) / start * 100
    cagr = ((end + dividends) / start) ** (1/years) - 1
    return total_return, cagr * 100

# Пример использования
start = 100000
end = 150000
dividends = 5000
years = 2

ret, annual = calculate_return(start, end, dividends, years)
print(f"Общая доходность: {ret:.1f}%")
print(f"Среднегодовая: {annual:.1f}%")

# Вывод:
# Общая доходность: 55.0%
# Среднегодовая: 24.5%
                    </code></pre>
                </section>

                    <h3>📈 Линейный график</h3>
                    <p><strong>Определение:</strong> Простейший вид графика, соединяющий точки цен прямыми линиями.</p>
                    <br>
                    <ul>
                        <li>✅ Простота восприятия</li>
                        <li>✅ Сглаживает рыночные шумы</li>
                        <li>✅ Хорошо подходит для долгосрочного анализа</li>
                        <li>❌ Не показывает волатильность внутри периода</li>
                    </ul>
                </section>
                
                <section>
                    <h3>📊 Пример линейного графика</h3>
                    <pre style="font-size: 0.55em;">
Цена
  ^
  |                    *
  |                   / \
  |                  /   \      *
  |                 /     \    / \
  |                /       \  /   \
  |               *         \/     \
  |              /                 \
  |             /                   \
  |            *                     \
  |           /                       \
  |          *                         *
  |_______________________________________→ Время
  
  Линейный график показывает общий тренд движения цены
                    </pre>
                </section>
                
                <section>
                    <h3>🕯️ Свечной график (Японские свечи)</h3>
                    <p><strong>Определение:</strong> График, показывающий цены открытия, закрытия, максимум и минимум за период.</p>
                    <br>
                    <p><strong>Строение свечи:</strong></p>
                    <ul>
                        <li><strong>Тело</strong> — между ценой открытия (Open) и закрытия (Close)</li>
                        <li><strong>Верхняя тень</strong> — максимальная цена (High)</li>
                        <li><strong>Нижняя тень</strong> — минимальная цена (Low)</li>
                    </ul>
                </section>
                
                <section>
                    <h3>📖 Расшифровка свечного графика</h3>
                    <table>
                        <tr><th>Цвет</th><th>Значение</th><th>Что означает</th></tr>
                        <tr><td>🟢 <strong>Зелёная/Белая</strong></td><td>Close > Open</td><td>Покупатели сильнее продавцов</td></tr>
                        <tr><td>🔴 <strong>Красная/Чёрная</strong></td><td>Open > Close</td><td>Продавцы сильнее покупателей</td></tr>
                    </table>
                    <br>
                    <p><strong>Что показывает длинная тень:</strong></p>
                    <ul>
                        <li>📌 <strong>Верхняя тень</strong> — был рост, но цена вернулась вниз (давление продавцов)</li>
                        <li>📌 <strong>Нижняя тень</strong> — было падение, но цена выросла (поддержка покупателей)</li>
                    </ul>
                </section>
                
                <section>
                    <h3>📐 Схема японской свечи</h3>
                    <pre style="font-size: 0.7em;">
      
      High ─┬─ ┐
            │  │  ← Верхняя тень
      Close ┤  ├─┘  (если Close > Open — зелёная свеча)
            │  
      Open  ┼─ ┐   ← Тело свечи
            │  │
      Low   ┴─ ┴   ← Нижняя тень
      
      
      ⚠️ Если Close &lt; Open — свеча красная (тело внизу)
                    </pre>
                </section>
