## Как запустить презентацию

### Способ 1: Через Live Server 
1. Откройте папку проекта в VS Code
2. Нажмите правой кнопкой на `index.html`
3. Выберите **"Open with Live Server"**

### Способ 2: Через браузер
1. Откройте файл `index.html` в любом браузере

## Управление презентацией

| Действие | Клавиша |
|----------|---------|
| Следующий слайд | → (стрелка вправо) или Пробел |
| Предыдущий слайд | ← (стрелка влево) |
| Вертикальные слайды | ↓ ↑ (стрелки вниз/вверх) |
| Открыть меню | Нажать на иконку ≡ в левом нижнем углу |
| Общий вид всех слайдов | ESC |
| Полноэкранный режим | F |
