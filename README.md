# Презентация Reveal.js

## Тема

Инвестиции

## Запуск проекта

1. Скачать проект
2. Открыть папку проекта
3. Запустить локальный сервер
4. Открыть файл index.html

## Используемые технологии

- HTML
- CSS
- Markdown
- Reveal.js

## Особенности

- Меню навигации
- Нумерация слайдов
- Markdown-слайды
- Отдельный CSS-файл
- Локальная библиотека Reveal.js
